# Notice

This repository is an unofficial, cleaned public artifact for portfolio and educational review.

## Source Boundaries

- The repository does not contain official train/test data, checkpoints, predictions, private logs, copied leaderboard screenshots, account state, or platform workspace paths.
- Public code and notes are derived from the author's competition workspace and have been sanitized for release.
- Exact final submission recipes and private run records are intentionally withheld.

## Data Handling

The code is designed to run on official data obtained through the competition's authorized channels. Do not commit official data, generated predictions, checkpoints, logs, user identifiers, screenshots, or local platform artifacts back into this repository.

Public EDA utilities should emit aggregate statistics by default. Any local diagnostic mode that materializes identifiers should be used only in a private workspace and should not be published.
